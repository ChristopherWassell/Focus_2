Focus 2

This repository is the second focus area of learning for my Automation learning. It will contain several examples of the use of Automation using Playwright and Typescript. 

How to use:

First Clone the repository:

Open your terminal 
Navigate to the directory where you want to clone the repository. You can use the cd command for this. For example, to navigate to your Documents folder:
cd Documents

Use the git clone command followed by the repo url. For this repo that would be:
git clone https://github.com/ChristopherWassell/Focus_2

Following the succesful clone, ensure you are in the repo root folder. You can use the cd command again, for this repo it would be:
cd Focus_2

Checkout main and ensure it is the latest version.
git checkout main

then followed by
git pull

To run the tests: npx playwright test --headed
